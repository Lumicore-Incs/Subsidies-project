# Customer Order Management System

A modern, clean React application for managing customer orders.

## Features

- ✅ Add customer orders with complete details
- ✅ Auto-generate unique customer IDs
- ✅ Store customer name, address, and contact number
- ✅ Track item name and quantity
- ✅ View order history
- ✅ Modern, responsive design

## How to Run

1. Install Node.js (if not already installed)
2. Open terminal in the project folder
3. Run: `npm install`
4. Run: `npm run dev`
5. Open browser to `http://localhost:5173`
